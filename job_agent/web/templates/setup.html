Profile Basics

These fields are referenced directly in generated CVs, applications, and form-answer packages.

How these values are used

Name, title, phone, email, LinkedIn, and current location appear in the at-a-glance CV and standard form answers. Address is stored for your convenience, but templates will only use it if you add {{ "{{ contact.address " }}}} to a template.

Availability and Preferences

These fields influence recruiter-facing wording, location fit, and digest filtering.

What can be included here

Use plain language. Availability and relocation text may be inserted into generated applications. Preferred regions help location scoring. Role interests are context for future matching and are safe to keep broad.

Score is 0-100. Around 45 includes exploratory roles; 60+ is stricter; 70+ mostly strong technical matches. Excluded roles can still be filtered out regardless of score if language or freshness is a blocker.
